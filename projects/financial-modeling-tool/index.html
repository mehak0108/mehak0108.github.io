Financial Modeling Tool

80%

Less eng time

Built an internal Retool app for the finance team to run scenario models without engineering dependency.

Problem

Every time the finance team needed a new scenario model, they raised an engineering ticket. Lead times averaged 2 weeks. The team was bottlenecked on analysis they should have been able to run themselves.

Solution

Using Retool and a shared data warehouse, I scoped and shipped a self-serve modeling tool that let finance analysts build and run scenario models with dropdown inputs, parameterized queries, and exportable outputs — no SQL or engineering required.

Outcome

Engineering time spent on finance modeling requests dropped 80%. The team shipped 3 major budget scenarios in the following quarter, all without any eng involvement.
